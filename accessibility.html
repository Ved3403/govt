Audio & Motor Assistance

Screen Reader Support

This site is optimized for NVDA, JAWS, and VoiceOver screen readers. ARIA landmarks and labels have been implemented across all interactive elements.

Voice Navigation & Search

Use the microphone icon in the search bar to search by voice. Say commands like "Go to Schemes" or "Open Help" when voice input is active.

WCAG 2.1 AA Compliance Overview

  • Perceivable

    Information and user interface components are presentable to users in ways they can perceive (e.g., text alternatives, adaptable layout, sufficient contrast).

  • Operable

    User interface components and navigation are operable (e.g., keyboard accessibility, sufficient time to read, naviagtion handles).

  • Understandable

    Information and the operation of the user interface are understandable (e.g., readable text, predictable behavior, input assistance).

  • Robust

    Content is robust enough that it can be interpreted reliably by a wide variety of user agents, including assistive technologies.
